# Public reading and publication verification

HTML is the primary public explanation. `/llms.txt`, `/content/how-it-works.md`,
`/content/public-pages.md`, and each Reviewer’s `/snapshot.txt` are generated
reading conveniences. They do not become a Product BR, formal Protocol record,
live GitHub API, or authorization to perform actions. The lifecycle Markdown is
exactly the source rendered by How Shoal works. Public facts and Join guidance
use the same governed content as visible HTML. Snapshot text derives solely from
the validated Network Projection and preserves readiness, selection, provenance
and absent metrics. External Policy/profile text never feeds metadata or these
machine-readable explanations.

Directory HTML contains a complete native link disclosure even when interactive
pagination shows only 50 cards. Join’s native disclosures are inside the existing
six-stage map, with Web and Local / CLI guidance in the same stages. Hydration
still enables search, sorting, stage selection and separately authorized actions.

## Deterministic gates

```sh
npm run build
npm run validate:seo
node scripts/validate-seo-contracts.mjs
```

Build requires a complete `SHOAL_PROJECTION_FILE`. Use
`SHOAL_PUBLIC_CONTENT_FETCH=skip` for fixtures without external public reads.
The fixture gate covers zero, one, 52 and changed Reviewer projections, current /
fallback / unavailable Summary, unsafe external strings, invalid identities and
intentional output drift. Production Network Scan runs the SEO artifact gate
before uploading a Pages artifact, so failure preserves the previous publication.

## Search appearance limits

The approved Shoal wordmark is 1200 × 403, social image 1200 × 630, favicon
256 × 256 and Apple touch icon 180 × 180. They remain the existing visual identity.
Structured data describes a Brand, WebSite and visible WebPage with applicable
breadcrumbs, without inventing a company, expertise, ratings or endorsements.

Google supports one search favicon per hostname, and does not support independent
site names at a subdirectory. `taco3064.github.io/shoal-app/` shares that hostname;
this delivery does not migrate domains or promise branded Google UI.
Google does not require `llms.txt` or special AI-only files for its AI features.
These files improve direct reading convenience, with no promise of crawler
support, indexing, ranking or arbitrary model-answer accuracy.

Sources:
- https://developers.google.com/search/docs/appearance/favicon-in-search
- https://developers.google.com/search/docs/appearance/site-names
- https://developers.google.com/search/docs/appearance/ai-features
- https://schema.org/Brand
- https://schema.org/WebSite

## After an accepted main deployment

Delivery’s pre-commit acceptance and exact-head PR CI do not publish a candidate.
Do not close #79 until the accepted merged main is deployed and live evidence is
recorded. Resolve the successful Network Scan / Pages deployment run, prove its
checkout is the intended main SHA, record the run URL, then run from that checkout:

```sh
node scripts/verify-publication.mjs <deployed-main-sha> <report-path.json>
```

This read-only check retrieves every projected HTML page, robots, sitemaps,
branding, generated reading files, island entrypoints and the transitive local
JavaScript/CSS dependency closure. It checks HTTP
status and content types, then validates retrieved artifacts against this exact
checkout’s governed content. Re-reading the projection prevents accepting a mixed
publication generation. The supplied SHA must be established by deployment
workflow evidence; an arbitrary SHA argument or HTTP response alone is not proof.

Record a clean-context, URL-only model/client exercise covering the five route
classes and false Star-exchange, ranking, live-metric and mutation-permission
claims. Preserve prompts, actual answers, any failures and corrected re-tests.
A single exercise is evidence for that client and publication only, never a
universal model-comprehension guarantee. External crawler and Search Console
observations remain reportable, not guaranteed gates.
